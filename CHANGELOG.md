# Changelog

## Unreleased

- Adopted as `software-technologies-limited/stl-rich-text-editor`.
- Replaced CKEditor 4 and KCFinder with an independent vanilla JavaScript editor.
- Removed all PHP framework and third-party runtime dependencies.
- Added PHP 8.1+ framework-neutral rendering and asset helpers.
- Added basic, standard, full, and custom toolbars.
- Added formatting, lists, links, images, tables, source and fullscreen modes,
  undo/redo history, word counts, paste cleanup, form synchronization, and upload hooks.
- Added defensive browser-side HTML sanitization.
- Replaced legacy CI with GitHub checks for PHP 8.1 through 8.5.

## 2.x and earlier

Original releases were maintained by 2amigOS! Consulting Group as a Yii 2
integration for CKEditor. See the Git history for details.
